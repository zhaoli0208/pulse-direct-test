# PULSE 手机直连测试版

用于验证新的免费入口能否在手机关闭 VPN 后正常游玩。包含《彩虹节拍》完整原曲、歌词、4/6 键与四档难度、跳转练习和全部现有设置。

网页和音乐都在 site/ 内，通过同源相对路径加载，无需原 chatgpt.site 网址，无外部字体、脚本或音乐依赖。

## 发布

将本目录推送到自己的公开 GitHub 仓库 main 分支。在仓库 Settings → Pages 中选择 GitHub Actions，再运行 Deploy PULSE test。发布地址以 GitHub 返回的地址为准。本地准备文件不表示已经发布。

仅仓库所有者及其主动授权的协作者可修改线上版本。公开仓库的文件可被他人查看和复制，不会因此获得原仓库修改权限。

## 手机验收

分别使用 Wi-Fi 和移动流量，关闭 VPN 后打开实际发布网址。检查首页、完整歌曲播放、歌词、4/6 键及进度跳转；再请朋友用不同网络测试。通过后再考虑迁移完整曲库。

原正式网站不受此测试包影响。本包不含账户、密码或上传凭据。

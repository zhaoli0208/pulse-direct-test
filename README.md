# PULSE / 节拍之间

## [▶ 点击这里直接游玩](https://zhaoli0208.github.io/pulse-direct-test/)

**手机、电脑浏览器均可 · 横竖屏切换 · 无需下载 · 无需登录 GitHub 或 ChatGPT**

100 首完整原曲、同步歌词，4 键 ASJK / 6 键 ASDJKL，四档难度，共 800 套谱面。蓝色点按、黄色同列与变轨接取、绿色长按、红色相邻列滑接。

把上面的游戏链接发给朋友，打开就能选歌游玩。手机不必点击最底部的小按键：整列轨道的上、中、下任意位置都能操作，支持多指点按、长按和跨列滑动；仍需在音符到达判定线时操作。

网页和歌曲均位于 site/，由 GitHub Pages 在同一网址提供；游玩无需登录 GitHub 或 ChatGPT，也不依赖原 chatgpt.site 网站。选歌后自动加载该首完整音频，首次游玩需要网络，不会一次下载全部曲库。

主界面可调整音乐音量、打击音量、音色、下落速度（1–20 倍）、输入补偿、中央歌词与简洁模式。默认音乐 100%、打击音效 60%、速度 5 倍，中央歌词关闭。鼓点背景脉冲已移除。顶部进度条可跳转练习；练习不保存最佳成绩。

成绩和设置保存在当前浏览器、当前网址中，不会自动从旧网址同步。整列触控和横竖屏切换更新仅发布到 GitHub 入口；谱面、歌词和歌曲不变。后续更新通过本仓库 main 分支发布。

## 部署

GitHub Actions 将 site/ 发布至 GitHub Pages。工作流只在 main 分支更新或手动触发时运行；其他分支上传曲库不会影响当前线上版本。只有仓库所有者与其主动授权的协作者可修改原仓库；公开文件（包括源码、谱面、歌词和音乐文件）可以被任何人查看和下载；Fork 或下载不会赋予修改本仓库的权限。

如果喜欢这个游戏，欢迎分享上面的直接游玩链接，也可以 Star 或 Fork 本仓库。下载源码请点击 Code → Download ZIP；这是网站源文件，直接游玩请使用上面的游戏入口。

site/media-manifest.json 记录全部歌曲文件的原始字节数与 SHA-256。verification.json 记录迁移时的源码及音频校验。用户提供的音乐文件未截短或重新编码。支持设备、网络和可用流量仍以实际测试及平台额度为准。

## 手机横屏 / 六指

在主界面“游玩画面”或暂停菜单的“屏幕方向”选择横屏，再选 6 KEYS 开始。也可在演奏顶部点击“切换横屏 / 切换竖屏”。默认跟随设备，选择会自动保存；演奏中改变方向会暂停，摆好手后继续。横屏将轨道铺满可用宽度，六指可以同时按住六列，每列的上中下任意位置都能操作。

浏览器无法锁定方向时，游戏画面自行旋转，触控坐标同步转换；把手机转到与画面一致即可。可选“全屏游玩”减少浏览器栏占用；不支持全屏的浏览器仍可切换游戏方向。手机系统的多指截屏等手势可能抢走触摸，六指操作前可在系统设置关闭相关手势。
